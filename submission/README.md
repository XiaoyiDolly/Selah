# Kaggle submission kit

This directory contains the upload-ready assets that can be prepared without access to the owner's Kaggle or YouTube accounts.

## Files

- [`kaggle-writeup.md`](kaggle-writeup.md) — 448 words including headings and links; the limit is 500.
- [`selah-public-notebook.ipynb`](selah-public-notebook.ipynb) — self-contained public companion notebook; no credentials, network, Node.js, or paid API required.
- [`video-script.md`](video-script.md) — a 2:58 script and storyboard.
- [`media/selah-cover.png`](media/selah-cover.png) — 1672×941, 16:9 cover image.

## Submission checklist

- [ ] Paste `kaggle-writeup.md` into the Kaggle Writeup editor as the title, subtitle, and body.
- [ ] Replace the notebook and YouTube placeholders in the Writeup with their final public URLs.
- [ ] Add `media/selah-cover.png` to the Media Gallery and select it as the cover image.
- [ ] Upload or import `selah-public-notebook.ipynb`, run all cells, save the output, make the notebook **Public**, and add it in **Project Files**.
- [ ] Record from `video-script.md`, keep the exported runtime at or below 3:00, and upload it to YouTube as **Public**.
- [ ] Attach the YouTube video in the Media Gallery.
- [ ] Set the Public Project Link to <https://github.com/XiaoyiDolly/Selah>.
- [ ] Open every submitted URL in a private/incognito window and verify that it loads without a login or paywall.
- [ ] Confirm that no credential, licensed Scripture text, private reflection, personal account detail, or real private PR data appears in the notebook, video, or repository.
- [ ] Preview the final Writeup and verify it remains under 500 words after replacing the two placeholders.

Account-bound publishing is intentionally not automated: the owner must publish the notebook on Kaggle, upload the video to YouTube, and submit the Writeup.
